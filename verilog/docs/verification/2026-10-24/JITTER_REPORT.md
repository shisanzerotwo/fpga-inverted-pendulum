# 平衡抖动修复报告：换装江协 V1.1 出厂等效参数（2026-10-24 晚）

问题：run1/run3 平衡为 ±15° 标准差稳定极限环（用户判定"抖动太大，要求尽量静止"）。

## 根因（量纲核算，非猜测）

alpha = (adc−ANG_OFFSET)×8.12988 cdeg/count（33300/4096）；输出 duty_x100（±10000=±100%，与江协 ±100 PWM 同构）；角度环 5ms / 位置环 50ms 与江协完全一致；同电机（25GA370+TB6612）、同电位器（SV01A103）。换算到同量纲后：

| 增益 | 旧值 | 江协 V1.1 出厂等效 | 偏差 | 害处 |
|---|---|---|---|---|
| 角度 Kp | 1.85 | 3.075 | ×0.60 偏软 | — |
| 角度 Kd | 18 | 5.043 | **×3.57 偏硬** | 每拍放大传感器噪声 → 高频抖振 |
| 位置 Kp | 40 | 4.228 | **×9.46 偏硬** | 长期顶 POS_TRIM 限幅，反复命令 ±10° 倾斜 |
| 位置 Kd | 400 | 37.07 | ×10.79 偏硬 | 同上放大 |
| 角度 Ki | 0.0615 | 0.1107 | ×0.56 偏软 | — |

佐证：run1/3 中 20ms 内 alpha 跳 30°（1500°/s）远超杆物理极限（~400°/s）——抖的是环路诱发的高频抖振，不是杆真实运动。Kd=18 是坏 ADC 时代为捕获鲁棒性故意加硬的（RTL 注释自认"4.5× reference"），新板 ADC 干净（手扶跨度 37）后失去存在理由。

## 改动

`top.v` pendulum_ctrl 实例化新增五参数覆盖（RTL 默认值不动，ctrl_tb 回归口径不受影响）：

`.KP_ANG(32'sd201528)` 3.075、`.KI_ANG(32'sd7255)` 0.1107、`.KD_ANG(32'sd330506)` 5.043、`.KP_POS(32'sd277056)` 4.228、`.KD_POS(32'sd2429568)` 37.07。

单位换算链写在 top.v 注释里（角度：PWM/count×100÷8.12988；位置：count/count×8.12988）。编译坑 26 告警 0；位流 SHA `48bfb088f14720708cd229c42c07a9d6cfef53e7af97b1308576281e4e23a6d0`，UserCode **0x74A8**，`--run 2` 烧录 Status 0x6020；烧后 STOP 核验通过（`stop_check_74A8.bin`）。

## 实测（用户手动上摆，`jitter_factory_run1.bin` 240s，两次上摆两次捕获）

| 指标 | 旧参数基线（run3） | 出厂参数 | 改善 |
|---|---|---|---|
| BAL alpha 标准差 | 1556 cdeg（±15.6°） | **227 cdeg（±2.3°）** | **6.9×** |
| 分 10s 窗标准差 | 1528~1589 恒定横盘 | 166~398（多在 ~200） | 持续安静 |
| \|duty\| 中位 / 均值 | 1641 / 2347 | **538 / 814** | ~3× 省力 |
| duty 饱和占比 | 4.4% | **0.4%** | 基本消失 |
| wdog / 断链 | 0 / 0 | 0 / 0 | — |
| BAL 时长 | 95.7s（窗口耗尽仍活） | 98.7s + 0.7s（两段，第二段为短二次上摆） | 同级 |

一次窗口两次手动上摆均成功捕获——更软的 Kd 未破坏捕获鲁棒性。alpha 峰值 ±24.4° 为进入/扰动瞬态，稳态多数时间 ±4° 内（用户肉眼判定"基本静止"）。

## 结论与边界

- **用户需求"平衡时抖动尽量静止"验收通过**：±15.6°→±2.3°。
- 江协"同硬件出厂免调"在本板成立；五参数为协同组整体换装（非单变量），后续如需微调在此基础上单变量进行。
- 剩余抖动为摩擦死区+杆物理极限内的微调动作，绝对静止不可达（摆不是刚性支撑）。
- 若后续出现"横杆低频游走"，下一杠杆是江协 PWM 偏移（0~5 等效，官方抖动排查第一软件项），本轮未加。
