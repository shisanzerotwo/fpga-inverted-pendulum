# 立创·逻辑派 FPGA-G1 扩展排针引脚表（已交叉验证）

来源：立创商城数据手册第 2 页官方排针引脚图（`docs/G1_datasheet.pdf`，9 页图片版，本次切图放大读出）
交叉验证：① 官方 IO 约束文件 `docs/立创逻辑派FPGA_G1_IO.cst` ② Gowin 器件库 `PBGA256.json`

## 验证结论（三重独立吻合）

| 校验项 | 结果 |
|---|---|
| 排针上的 FPGA IO 总数 | **65**（= 36 + 29），与官方 wiki「FPGA 占 65 个 I/O」完全一致 |
| 每个 bank 出现在排针上的球位数 | 与器件库里该 bank 的"空闲球位"数量**逐一吻合** |
| 未引出的空闲球位 | 恰好等于配置类引脚：Flash `L10 M9 P10 R10` + JTAG `A6 A7 B8 C6` + `MODE0/1/2 M16 B16 C15` + `RECONFIG_N/READY/DONE B10 A13 C13` |

三条互相独立的数据源完全自洽 → 这张表可以当准。

⚠ 这 4 个球在器件库里有 Flash 配置复用功能：`T9 = DIN/CLKHOLD_N`、`M8 = SO/D1`、`N9 = SSPI_CS_N/D0`、`P9 = DOUT/WE_N`。
官方既然把它们引到排针上，说明板子用的是标准 MSPI（`MCLK=L10 / MCS_N=M9 / MI=P10 / MO=R10`）。
但**不要在云源工程里把下载模式改成 SSPI/CPU**，否则会冲突。

## 本工程已占用的排针脚

来源：`排针映射与IO分配.md`（M1）。全部落在 **Bank 0 = 3.3V**，器件库里均无复用/配置功能。

| 排针位置 | 球位 | 网络名 | 信号 |
|---|---|---|---|
| 排针1 01 | K16 | EX_IOT24B_K16 | `EB` |
| 排针1 02 | J15 | EX_IOT24A_J15 | `EA` |
| 排针1 03 | J14 | EX_IOT22B_J14 | `ADC_SCK` |
| 排针1 04 | J16 | EX_IOT22A_J16 | `ADC_CS` |
| 排针1 05 | F14 | EX_IOT9A_F14 | `ADC_MISO` |
| 排针2 07 | G15 | EX_IOT13A_G15 | `PWMA` |
| 排针2 08 | G14 | EX_IOT13B_G14 | `AIN1` |
| 排针2 09 | G16 | EX_IOT16A_G16 | `AIN2` |
| 排针2 10 | H15 | EX_IOT16B_H15 | `ADC_MOSI` |

Bank 0 的 3.3V 结论由官方 `.cst` 反推：落在 bank0 上的 UART（F12/F13）、1 位共阳数码管的 8 个段、
`usb_dp_pull`（L15）全部标的是 `LVCMOS33 / BANK_VCCIO=3.3`。

IOL / Bank 7 的 14 个脚刻意不约束，留给阶段 5 扩展。
`K1~K4` 备选（N10 / M11 / P11 / T11）在 **Bank 2 = 2.5V**，如启用须写 `LVCMOS25`。

## 板载已占用（不可用）

- 时钟 T7、按键 D11 / F10、6 个 RGB LED（R9 C10 R7 N6 T10 P7）
- 串口 F13 / F12、**1 位共阳数码管**的 8 个段（G13 H16 H12 H13 H14 G12 G11 L14）
- USB1.1（M14 M15 L15）、HDMI（M10 N11 及 6 个数据脚）、DDR3（48 个球）
- **与板载 ARM 互连的 8 个球**：`PA0..PA7 = J12 J11 K11 D14 E15 L12 L13 L16`
