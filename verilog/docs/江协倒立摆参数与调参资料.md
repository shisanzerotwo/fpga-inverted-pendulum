## 2. 控制结构：串级双环 PID

来源：15/16 号程序 `User/main.c` + `User/PID.c`。

- **内环 = 角度环**（快环，5ms 一拍）：Actual 来自角度传感器 AD 原始值（0~4095），输出直接给 `Motor_SetPWM()`。
- **外环 = 位置环**（慢环，50ms 一拍）：Actual 来自编码器速度累加（`Location += Speed`），输出**不直接驱动电机**，而是偏置内环目标：`AnglePID.Target = CENTER_ANGLE − LocationPID.Out`（让摆杆微微倾斜产生水平力拉回横杆）。
- **PID 公式**（位置式）：`Out = Kp·e0 + Ki·∑e + Kd·(e0 − e1)`，输出限幅钳位。
- **调试友好设计**：Ki=0 时误差积分直接清零，防止调试中途开 Ki 时积分早已积累导致疯狂输出（`PID.c`）。
- **保护**：摆杆角度超出中心区间 → 自动停 PID、PWM 清零（倒下停机）。
- **时基**：TIM1 1ms 中断统一采样；角度环 5ms 分频、位置环 50ms 分频、按键 Tick 1ms。

## 4. 自动启摆（16 号程序 + V1.1）

| 参数 | 教学版 16 | V1.1 默认 | 官方可调范围（pid-3） | 调节判据（官方注释） |
|---|---|---|---|---|
| 启动力度 START_PWM | 35 | 35 | **25~45**（菜单 0~100） | 摆不上去加大；摆过头转整圈减小 |
| 启动时间 START_TIME | 100ms | 90ms | 0~200（一般不改） | 过短力发不出来；过长不利共振 |

状态机（教学版）：`0` 停止 → `1` 判断（每 40ms 采 3 次角度，中间一次为极值 → 判定左/右最高点）→ `21~24` / `31~34` 左/右打一拍（PWM→延时→反向 PWM→延时）→ 反复注入能量 → 连续 2 次采样落入中心区间 → 位置/积分清零 → `4` 切入双环 PID。首次启动强制先向左打一拍，使摆杆离开传感器盲区。

## 6. 官方调参说明（pid-3 页要点，2026-10-24 抓取）

- **中心角度标定**：手动把摆杆扶到竖直，读角度环 Act 值即中心角度（有抖动，取近似）。不准的后果：横杆正/反转一圈速度不一致、位置环稳态误差、偏差过大无法启摆。
- **PWM 偏移**（输出偏移，V1.1 菜单 0~50、典型 0~5）：加快 PID 输出响应、弥补电机死区差异。**过小 → 横杆低频抖动；过大 → 摆杆高频抖动**。这是官方抖动排查第一软件项。
- **操作**：K1 启停（PC13 LED 指示）；K2/K3 顺/逆时针转一圈；K4 依次切 角度环 Kp/Ki/Kd → 位置环 Kp/Ki/Kd → 更多系统参数；电位器 RP1/RP2/RP3 对应调 Kp/Ki/Kd，OLED 数值矩形框空心=电位器不在档位，缓慢拧到实心才生效。
- **保存/重置**：倒立摆界面长按 K4 写 FLASH（掉电不丢）；系统选择界面长按 K4 恢复出厂；**新烧录芯片参数可能全 0，须先重置**。
- **抖动综合排查**：硬件先拧紧全部螺丝（尤其固定轴 6 个顶丝），软件再动 PWM 偏移与两环 PID。

## 7. 改进算法阈值速查（教学程序 02~11 实测值）

02~11 号程序的 Kp/Ki/Kd 均为电位器在线调，范围 0~2；定速目标 −150~150（计数/ms）、定位置 ±408。

| 程序 | 机制 | 固定阈值 |
|---|---|---|
| 06 | 积分限幅 | ErrorInt 钳位 **±500** |
| 07 | 积分分离 | \|误差\| < **50** 才积分 |
| 08 | 变速积分 | 积分速度系数 C∈0~1（注释：本身不防饱和，需另加限幅） |

## 8. 社区调参机理笔记（曲线结论与经验法则）

来源：博客园江协 PID 笔记（19464214）、CSDN 倒立摆实现笔记（150397720），2026-10-24 抓取。

- **位置环 PD 曲线**（目标 0）：Kd=0 → 振荡衰减不掉（P/I 每次反向调节因惯性超调）；Kd=2 → 振荡减小但仍有尾振；**Kd=4 → 曲线平稳**。与源码取值互证。
- **Kp 序列**（0.25→0.5→0.75→1）：Kp 越大稳态误差越小，但超调越大，稳态误差始终不消除。
- **经验法则**：电机**定速控制用 PI**（一般不振荡）；**定位置控制用 PD**（可加少量 I，I 加大反而极不稳定——平衡类项目对 I 滞后极敏感）。
- **稳态误差机理**：纯 P 下 Kp·e(t)=f(t)（摩擦力），摩擦非零则 e 必非零；I 靠累积维持恒定驱动力对抗摩擦。
- **启摆两条路线**：脉冲法（江协 16 号状态机，最高点打一拍共振储能）vs 能量法（按机械能差生成指令）。切 PID 前建议对速度做**软钳位/低通**防突跳。
- **调试顺序**：标中心角度与电机/编码器极性 → 单调角度环（Kp 到"快而不抖"，Kd 抑制超调）→ 再开位置环（先只加 Kp）→ 最后接启摆与越界保护。

## 10. 本工程（FPGA）移植对照与建议

1. **量纲绑定**：江协参数绑定它的标定——PWM ±100 @20kHz、速度=计数/ms、角度=AD 原始值。FPGA 端沿用同电机/同传感器时，角度环 Kp 0.25~0.3 / Ki 0.009~0.01 / Kd 0.4~0.41，位置环 Kp 0.4~0.52 / Ki 0~0.01 / Kd 4~4.56 可直接当起点。
2. **中心角度必须自标**（官方方法：手动竖直读 AD）。注意 10-24 排障记录里的 adc≈3848 是断链诊断值，**不是**竖直标定值，勿混用。
3. **控制周期对齐**：1ms 采样 / 5ms 角度环 / 50ms 位置环的分频结构与 PWM 20kHz 频率是这套参数成立的前提，FPGA 端时序应保持同级。
4. **对症当前问题**："横杆低频抖动"按官方口径先查 PWM 偏移（0 起步，0~5 微调）再动 Kd；"震荡收敛"对应社区曲线 Kd 不足段（Kd=2→4 方向）。位置环 Ki 建议保持 0 或极小 + 积分分离（阈值量级 100）。
5. **机制借鉴**：Ki=0 清积分（调试安全）、倒下自动停机 + 越界保护（对应我们的看门狗需求）、启摆状态机的"40ms 三点采样找最高点 + 中心区间双侧清零切入"。
