# 项目需求进度与验收状态

**状态日期：2026-10-24。** 本页按“源码实现、仿真通过、实物验证、需求验收”区分进度。仿真 PASS 不等于实物通过；更换新板后，旧板上的 ADC/起摆/平衡结果不能作为新板验收证据。

## 当前阶段

用户确认 ADC 修复已通过，旧板已更换为相同型号新板；GD32固件与FPGA位流均已由用户报告烧入。设备码读取确认FPGA UserCode `0x0000FD3D` 与当前位流一致；COM9的381帧遥测全程为STOP、duty=0、enable=0、braking=1、link=1、key=1。当前配件板12V关闭、USB保留、ARM/STOP、未按KEY1（现场档位切换前须重新确认）；下一步先在12V关闭时切到FPGA档并核验STOP，再采供电状态下的角度基线、重标`ANG_OFFSET`。12V关闭遥测不用于角度标定；GD32 Flash未读回比较。操作与数据入口见[下一次执行入口](verification/2026-10-23/NEXT_SESSION.md)及[新板STOP复核](verification/2026-10-24/new_board_stop_verified.md)。

## 推进顺序

保持FPGA档、STOP且不按KEY1；准备采集时打开配件板12V，确认遥测安全字段持续有效，分别采自然下垂、竖直朝上和返回下垂数据。根据稳定窗口统计量重标`ANG_OFFSET`，重新构建/加载位流并核验UserCode与STOP输出；然后依次做起摆、平衡、轻推恢复、位置移动实物验收。角度基线和位流未确认前不启动电机。
