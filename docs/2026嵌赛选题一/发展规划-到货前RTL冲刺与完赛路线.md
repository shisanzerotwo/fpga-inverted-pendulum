## 一、现状与三个关键判断

**现状**（2026-09-29）：阶段 0 建模仿真 ✅、阶段 1 环境验收 ✅；阶段 2~6 全部等硬件。唯一阻塞 = 物流。

1. **80% 的剩余工作不依赖硬件**：排针映射、.cst、四类 RTL 模块、TB、定点化对拍，全部可在板卡到货前完成并验证。硬件到货只是把"仿真里已验证的系统"搬上板。
2. **最大技术风险已从"控制律是否可行"转移为"定点化 + RTL 实现是否保真"**：阶段 0 在浮点域证明了双环 PID + 能量起摆可行；参考答案（STM32 版）本身是**整数码值域**运算，照搬即天然定点——比"浮点算法→定点化"低一个量级的风险。
3. **验证策略是"对拍"而非"自证"**：Python 仿真（已验证）产生激励与期望值 → RTL TB 逐拍比对。沿用本项目纪律：模型不能批准自己的完成。

## 二、阶段 1.5：到货前 RTL 冲刺（W1~W4，不依赖硬件）

### W1 —— 排针映射定稿 + 正式工程骨架

- 数据源：`逻辑派FPGA-G1/06逻辑派硬件素材/extracted/01.素材/Gerber/源文件（嘉立创EDA专业版格式）` + 官方引脚分配表 + GW2A-18 Pinout 手册，**三方对照双证**（纪律 §1.5-3）。
- 方法：EDA 源文件网络标号 → 排针 pin ↔ FPGA pin 映射表；与官方 `立创逻辑派FPGA_G1_IO.cst` 交叉核对。
- 产出：`inverted-pendulum/fpga/pendulum/` 正式工程（.gprj + build.tcl + pendulum.cst，含 `set_option -use_sspi_as_gpio 1`）。
- **验收 M1**：全部待用引脚在 Pin Planner 无冲突；gw_sh build.tcl 一键综合通过；映射表落盘（含三源对照记录）。

### W2 —— 采集链 RTL + 单元 TB

| 模块 | 要点 | TB 验收 |
|---|---|---|
| `quad_decoder.v` | 编码器四倍频 + 方向 + 消抖滤波 | 正交波形发生器激励，断言 408 计数/输出轴圈、正反转对称 |
| `adc_bridge.v` | **已取消**（无外购 ADC 芯片，方案改走板载 GD32 ADC）→ 改做从 GD32 接收 12bit 码值 | 独立 UART 发送器激励；断言帧还原、校验丢弃、垃圾后重同步、超时 stale |
| `seg_display.v` | **1 位数码管（8 段 A~G+DP，共阳低有效；无位选、不需扫描）**显示摆角/目标 | 段码译码断言（官方段码表 0=0xC0…9=0x90） |
| `uart_tx.v` | 调试回传（θp/θa/PWM 三通道帧） | 波特率 115200 帧格式断言 |

- **验收 M2**：4 个模块 TB 全绿（**iverilog**，`E:\FBGA\oss-cad-suite`；ModelSim 未装、Gowin 内置仿真器未验证），综合资源占用 <20% LUT。

### W3 —— 控制律 RTL（整数域）+ Python 对拍

- `pid_angle.v`（摆角环 200Hz）/ `pid_pos.v`（位置环 20Hz）：**整数码值域照搬参考答案参数**（Kp=0.3/Ki=0.01/Kd=0.4 乘 256 定标或纯整数比例，实现时定标系数落文档）；含积分限幅（阶段 0 教训 #②b）与输出限幅。
- `energy_swing.v`：能量控制起摆，E = ½ω_p² + (1−cosα)·g/l 的定点展开；ke=5000 按定标重算；泵能方向常数留给实物裁决（阶段 0 纪律 #2）。
- `fsm_mode.v`：IDLE→SWING→捕获（±500 码值窗、连续两拍）→BALANCE→POSITION。
- **对拍框架（本阶段核心）**：`sim/run_sim.py` 新增 `export_vectors()`——把已验证的仿真场景（稳摆扰动 / 起摆 / 位置阶跃）逐拍导出为激励向量 + 期望 PWM 序列；TB 用 `$readmemh` 灌入，DUT 输出 dump 回 Python 比对，容差 ±2 LSB。
- **验收 M3**：3 组场景对拍全过；任一拍超差即定位到模块级归因（不允许"整体差不多"）。

### W4 —— 顶层集成 + 上板预案

- `top.v` 全系统集成 + 冒烟 TB（节拍频率、模块握手、按键去抖、模式切换边界）。
- 闭环联合仿真（RTL 控制器 × Python 被控对象）为 **stretch goal**：做不到就靠 W3 对拍 + 上板分模块验证兜底，不硬做。
- 到货 checklist 落盘 `docs/到货checklist.md`：装配（法兰切面朝上/顶丝）→ PH2.0 万用表核位 → FPGA 空板 LED/按键/数码管验证（= 顺带验证 W1 的 .cst）→ 接线 → 上电顺序。
- **验收 M4**：一键 build 出比特流；50MHz 时序收敛（报告留档）；checklist 评审过。
