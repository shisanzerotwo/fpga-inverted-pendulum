## 四、操作步骤（约 5~10 分钟）

1. **先拍全景照**：把整块板拍一张，能看清 4 条排针（H1~H4）与丝印；再对每条排针对特写拍 1 张（共 4~5 张）。
2. **读丝印**：排针丝印就是 **FPGA 球号**（形如 `G15`、`J15`）或 ARM 引脚名（形如 `PB0`）。
3. **逐行填表**：在上表「实物丝印实读」栏填你实际看到的字符；一致打 ✓，不一致就把实读值写下来（**以丝印为准**）。
4. **万用表抽查 2~3 脚**（可选，但建议）：
   - 找排针上的 `GND` 脚，与板子 `GND` 测通断（应导通）
   - 找 `3V3` 脚，测对 GND 电压（应 3.3 V）
   - 目的只是确认丝印标注与电气身份不矛盾，不要求逐脚测。
5. **把结果回给我**：直接贴表格内容，或把照片给我。

## 六、备选：不想读丝印的话（更硬，但需一根杜邦线）

把待验证引脚全部配成「输入 + 内部上拉」，用串口（`COM9`）循环回传各位电平；你用一根线把某个排针脚短到 `GND`，看哪个 bit 变成 0 → 直接证明「该物理脚 = 该球号」。
**代价**：要写一个临时测试比特流（占用 FPGA 侧工时），且需要接线；**不推荐**，除非丝印磨损看不清。
