## 一、赛题与合规要求

来源：《FPGA 创新设计赛道选题指南》（高云半导体，2026）

### 1.1 设计要求
- 系统通过**角位移传感器与编码器**实时采集摆杆倾角、电机转速与方向；**FPGA 作为主控计算平台，在其内部实现姿态控制算法**，输出 PWM 驱动直流电机，实现摆杆稳定直立。
- 稳态下具备摆臂定点位置调节能力（维持摆杆不倒的同时完成指定位移控制）。

### 1.2 基础要求（必做）
| # | 要求 | 对应实现阶段 |
|---|---|---|
| ① | 起摆控制：静止下垂摆杆被抬起，停在垂直位置附近 | 阶段 4 |
| ② | 自平衡控制：长时间稳定保持在垂直平衡位置 | 阶段 3 |
| ③ | 平衡后无明显震荡；抗轻微外力、短时间恢复 | 阶段 3（验收指标） |

### 1.3 拓展要求（冲分项）
| # | 要求 | 对应实现阶段 |
|---|---|---|
| ① | 键盘/拨码设定目标位置，电机平滑移动并保持静止 | 阶段 5 |
| ② | 电机按特定速度曲线/轨迹运动，同时保持摆杆不倒 | 阶段 5 |
| ③ | 位置控制全程摆杆保持直立 | 阶段 5（验收指标） |

### 1.4 关键规则
- 板卡免费申请：报名时同时勾选；**每队限一块**；评审通过后**抽取**寄送；**完赛须寄回**（广州黄埔）。
- 免费板对应：J280→选题一。**自备开发板合法**（第三方以高云 FPGA 为核心的板卡）。
- **【2026-09-27 确定】J280 未申请到，硬件路线正式锁定："自备逻辑派 G1 + 江协倒立摆套件"为唯一参赛方案**（GW2A-LV18 核心满足自备板条款；机构/传感/驱动由江协套件等效覆盖）。
- 申请渠道：https://www.gowinsemi.com.cn/university/boardapply/2026
- 技术支持：官方 QQ 群 213923272 / 高云官网 / 高云 B 站课程。

### 1.5 合规红线（全队共识，写进设计文档）
1. **姿态控制算法（感知→滤波→控制律→PWM）全链路在 GW2A 内用 RTL 实现**。GD32F303（板载 M4）在最终作品中**保持空闲**；答辩口径："赛题要求 FPGA 主控，M4 仅保留为非参赛辅助"。
2. 严禁把控制算法放进任何 MCU（包括套件原配 STM32）。
3. 引脚级结论必须"原理图 + 源码"双证后才进约束文件（本项目已踩过 PDF 解析错位的坑）。
4. 【2026-09-29 口径确认】MCU 侧**允许做纯数据采集转发**（ADC 采样 → 原始码值直传 FPGA，无滤波/无运算/无控制决策），不违规；但本项目主方案仍为外置 SPI ADC + MCU 空闲（链路延迟可控），板载 ADC 仅作应急备份。

## 二、硬件平台（全部已核实）

### 2.1 三方组合

| 部分 | 型号 | 角色 |
|---|---|---|
| 主控 | 立创·逻辑派 FPGA-G1（GW2A-LV18PG256C8/I7，55nm，20736 LUT4 / 15552 FF / 2 PLL / DSP） | 控制全链路（RTL） |
| 运动机构 | 江协科技 PID 倒立摆套件（原配 STM32 仅作参考实现，不入最终作品） | 机构 + 电机 + 传感 + 驱动 + 电源 |
| 补件 | SPI ADC 模块（**MCP3202/MCP3204，12bit SPI**） | 摆角电位器模拟量数字化——**主路径**：FPGA 侧无 ADC，外置 SPI ADC（12bit 满足"≥10 位"要求，SPI 单次传输 ~13µs）。**备用路径**：板载 GD32F303 自带 ADC，纯采集转发应急（见 §1.5-4 与 §2.2 注） |

### 2.4 STM32 参考实现参数（"参考答案"，来源：16-倒立摆-自动启摆 源码）

```
控制节拍：1kHz（TIM1）
摆角环：200Hz  位置式 PID  Kp=0.3  Ki=0.01  Kd=0.4  输出限幅 ±100
位置环：20Hz   位置式 PID  Kp=0.4  Ki=0    Kd=4    输出限幅 ±100
PID 公式：Out = Kp·E0 + Ki·∑E + Kd·(E0−E1)；Ki=0 时积分强制清零
位置环输出直接修正摆角环目标（Target = CENTER − LocOut）
起摆：±35% PWM 各 100ms 往复激励 → 每 40ms 采三次摆角做极值检测
      → 摆角进入垂直位 ±500 码值（≈±40°）且连续两拍在窗内 → 切平衡并清积分
PWM：20kHz，占空比 ±100 级（int8 范围内）；正转 AIN1=0/AIN2=1，反转相反
编码器：四倍频，每控制拍读增量（TIM3 编码器模式 TI12，滤波 0xF）
摆角 ADC：12bit 裸采样无滤波；垂直位 CENTER_ANGLE≈2010（装配决定，需实测校准）
按键：K1 启停 / K2 +1圈 / K3 −1圈（±10 圈限幅）；20ms 去抖、释放沿触发
两版（手动/自动起摆）PID 参数完全一致 → 平衡环参数独立于起摆层，可直接复用
```

## 三、接线表（定稿；拔掉套件上的 STM32 板，FPGA-G1 接控制板排针）

| 信号 | 控制板排针（STM32 引脚） | 方向 | FPGA-G1 侧 |
|---|---|---|---|
| PWMA | PA0 | → 板 | PWM 输出（20kHz） |
| AIN1 / AIN2 | PB12 / PB13 | → 板 | 方向 GPIO（正转 0/1） |
| EA / EB（电机编码器） | PA6 / PA7 | 板 → | 四倍频解码输入 |
| 摆角 OUT | PB0 | 板 → | **经外置 SPI ADC（MCP320x）→ FPGA**；应急备选：飞线至 GD32 ADC 通道（PA0~PA7 排针）采样后转发（延迟数十 µs，200Hz 控制周期下占 ~1%，可用但不作主方案） |
| K1~K4 按键 | PB10 / PB11 / PA11 / PA12 | 板 → | 输入（低有效，上拉） |
| UART | 串口排针 PA9/PA10 | 双向 | 调试曲线回传 |
| GND | — | — | **与 FPGA 板共地（必须）** |

供电：12V 适配器 → 控制板 DC 座（TB6612 VM + MP1584EN 3.3V）；FPGA-G1 独立 5V（USB 或独立电源），仅共地。
**上电前必做**：PH2.0-6P 接口在"控制板原理图"与"编码电机文档"中引脚序号标注不一致（公/母座视角镜像）——以控制板丝印为准，先不插电机用万用表确认 3V3/GND 位置再插。

## 四、技术方案

### 4.1 FPGA 内部架构

```
顶层（50MHz sys_clk）
├── 采集链
│   ├── 编码器四倍频解码器（408 计数/输出轴圈，含消抖滤波）
│   ├── ADC 驱动（SPI：MCP320x / I2C：ADS1115）→ 摆角码值
│   └── 零点校准 + 码值→角度换算（12bit 满量程 = 333°）
├── 控制律
│   ├── 模式状态机：IDLE → SWING(能量控制起摆) → 捕获 → BALANCE → POSITION
│   ├── 摆角环 PID（200Hz 起步，参数照抄参考答案，+积分限幅抗饱和）
│   ├── 位置环 PID（20Hz，输出修正摆角环目标，目标经梯形速度规划斜坡化）
│   └── [阶段5] LQR 状态反馈 u=-Kx（x=[θp, ωp, θa, ωa]）替换双环 PID
├── 执行链：PWM 发生器（20kHz；阶段5 提分辨率至 10bit）+ 方向输出
├── 方向映射边界：ANGLE_SIGN / MOTOR_SIGN / ENC_SIGN 三个安装常数在此单点定义
├── 人机：按键扫描（20ms 去抖/释放沿）→ RGB LED 状态色 + 数码管角度显示
└── 调试：UART 回传 θp/θa/PWM → SerialPlot 实时曲线
```

### 4.2 两阶段策略

- **阶段 A（保底）——复刻参考答案**：参数照抄 STM32 版，同机构上先跑 STM32 版再跑 FPGA 版，SerialPlot 同图对拍，行为一致即通过。优势：套件原配 STM32 就是天生的对照平台。
- **阶段 B（冲分）——超越参考答案**：
  1. LQR 替换双环 PID，把平衡抖动从参考答案的 ±15° 量级压到 ±3° 以内（对应赛题"无明显震荡"，核心差异化点）；
  2. 摆角环 200Hz → 1kHz、PWM 100 级 → 1024 级；
  3. 拓展①②③（位置控制/梯形速度轨迹/移动中直立）。

### 4.3 阶段 0 仿真结果（2026-09-27，代码 `inverted-pendulum/sim/`）

| 场景 | 结果 | 结论 |
|---|---|---|
| ① 稳摆+抗扰（5° 入稳，±15° 扰动×2） | ✅ 0.08s 入稳，扰动后峰值 6.9°，末段 0.9° | 江协双环 PID 参数在小扰动工作点**复刻成立** |
| ② 自动起摆（179° 静止） | 江协固定甩摆 12 组参数扫描**全败**；**能量控制起摆 ✅ ke=5000 时 0.26s 入稳** | 甩摆激励节奏依赖摆自然周期（占位模型 0.73s），对物理参数敏感；**FPGA 版采用能量控制起摆** |
| ②b 大扰动 20° 敏感性 | ✅（预期失败复现）0.43s 后积分饱和出窗停机 | 码值域 Ki=0.01 对大误差积分失控 → **FPGA 版必须加积分限幅** |
| ③ 位置阶跃 ±1 圈（硬阶跃） | ❌ 位置环输出打满 → 摆角目标瞬偏 8° → 出窗停机 | 硬阶跃不可用 → **位置目标必须经梯形速度规划斜坡化**（同时满足拓展②） |
| ④ LQR | K = [−4.47, −145.44, −5.77, −19.33]（占位模型） | LQR 框架就绪，实物参数实测后重算 |

**三条工程纪律（本阶段实测教训，进 FPGA 设计规范）**：
1. **方向常数单点边界**：ANGLE_SIGN（传感器）/ MOTOR_SIGN（电机）/ ENC_SIGN（编码器）是三个独立安装常数，只在"安装坐标↔物理坐标"边界模块定义一次；能量起摆在物理坐标直接算力矩，不经过方向映射（重复应用会把泵能变耗能——已实测复现）。
2. **泵能方向经实验裁决**：本模型坐标系下 τ ∝ (E−E_ref)·sign(ω_p·cosα)；文档公式的坐标约定不可盲抄， bring-up 时用开环 bang-bang 对照实验实测裁决。
3. **增益要匹配捕获带**：能量控制增益过小泵不动（稳态能量误差卡在摩擦平衡），过大抖振跳过捕获带；ke=5000 在占位模型下恰好——实物按实测参数重扫。
