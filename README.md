# fpga-inverted-pendulum

2026 年嵌入式竞赛 FPGA 赛道 · 选题一：**基于 FPGA 的实时姿态控制系统（旋转式倒立摆）**

- 主控：立创·逻辑派 FPGA-G1（高云 GW2A-LV18，自备板）
- 运动机构：江协科技 PID 倒立摆套件（编码电机 + 360° 电位器）
- 合规要求：姿态控制全链路（感知→滤波→控制律→PWM）以 RTL 实现于 FPGA 内部，MCU 保持空闲

## 目录结构
